# Anjali Elastomer — International Animated Homepage

A responsive one-page railway engineering website built with HTML5, Tailwind CSS 3 Play CDN, custom CSS and vanilla JavaScript. The interface follows the supplied international railway website references while retaining Anjali Elastomer's own content, products, projects, clients and contact information.

## Run locally

1. Extract the ZIP.
2. Open the project folder in VS Code.
3. Run with the VS Code Live Server extension, or open `index.html` directly.

For the smoothest video and browser behavior, Live Server is recommended.

## Main features

- Cinematic glass-header hero with a smooth 720p/30 FPS railway film, playback control, animated typography and 3D train parallax
- International responsive typography with animated gradient headings, crisp high-contrast body copy and staggered mobile-menu text reveals
- Responsive mega-menu dropdown navigation and mobile accordion menu
- Railway-themed 75% right-side mobile/tablet drawer with 25% page visibility, backdrop close, equal menu spacing, controlled scrolling, Escape support and breakpoint-safe submenus
- Mobile parent labels and always-visible plus controls both open desktop-inspired submenu panels with clear borders, active states and automatic in-drawer scrolling
- Dual-image cinematic About section with four animated 3D information cards
- Animated 3D Pan-India business map with project/bridge/plant tabs and 175 km / 60 bridge metrics
- Scroll progress, reveal effects and active-section navigation
- Animated company statistics
- Smooth auto-playing project slider plus continuously moving, single-row product and article marquees with drag/swipe and arrow controls
- Premium Featured Articles cards with responsive editorial typography, category/date metadata, reading-time badges, HD image treatment and animated progress
- Bright white HD product cards with active 3D depth, lighting and hover motion over an animated railway background
- Complete 14-logo client showcase over a full-colour, automatically managed looping railway-video background without a blue tint
- Playable full-screen HD engineering video modal
- Responsive layout and reduced-motion accessibility support
